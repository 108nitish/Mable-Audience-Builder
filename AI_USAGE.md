# AI usage

AI assistance was used for architecture brainstorming, implementation scaffolding, UI copy and styling iteration, test-case brainstorming, and documentation drafting. The final implementation was reviewed for the required API contract, validation rules, deterministic seed behavior, SQL parameterization, AND semantics, boundary convention, Docker networking, accessible native controls, retry behavior, and frontend/backend separation.

Correctness-sensitive logic was manually reasoned through against the assignment examples and covered with backend tests. AI-generated suggestions were treated as drafts; the candidate remains responsible for the code, trade-offs, and final review.
